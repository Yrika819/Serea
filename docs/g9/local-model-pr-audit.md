These stacked branches are not safe wholesale cherry-pick sources.

## What must be brought into G10-A

No code from these nine PRs is required wholesale before a Fake Backend spike. Carry forward #185's fresh-consent rule as a testable invariant. Reuse existing main code: `LocalModelChatAdapter`, `LocalModelAuthorizationRegistry`, egress contract and Usage/Egress wrappers. Create tests proving cancellation and backend lifecycle serialization without JNI/model artifacts. Defer native artifact/ARM64 runtime stack (#165/#166/#169/#178/#179/#182) and optional Android trim callback (#195/#198) until after the fake composition spike; trim coalescing/runtime memory guarantees are required before shipping or loading a real model, not before a fake backend test.

Security caveat: main Adapter validates that a consent proof is present and matches selected model, while one-use freshness is enforced by the authorization registry/Egress stage. G10-A must exercise the full registry → Egress → Usage → Adapter chain. An Adapter-only unit test does not prove one-use consent.
