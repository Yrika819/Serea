The Q8_0/BF16 `mmproj` files are optional vision projectors and are additional storage. MTP packs bundle a draft head with the model pack; DFlash2 files are separate draft models. The 9B repository and revision are public, but this does not imply any Serea compatibility or runtime result.

The model cards describe Qwen3.5-derived hybrid-attention vision-language models. Language weights are ternary `{-1,0,+1}` with FP16 group scales. The listed packs are **PTQ1_0** (dense trits), **PQ2_0** (Prism group-128, 2-bit slots), and **Q2_0** (upstream group-64 variant); the card says the runtime applies the matching activation transform for a blockwise Hadamard rotation folded into stored weights. A separate sign-flip requirement is not stated in these cards and was not independently established. For text-only use the separate vision projector is optional; it increases model-file storage if included. Cards list a 262,144-token inherited context, but this is model metadata, not a measured Serea limit or performance result. The current Serea adapter accepts only context up to 512 tokens on this runtime. Prism's card recommends at least 8,192 output tokens for thinking mode; Serea's diagnostic currently uses at most 32 output tokens, so a short non-thinking configuration would need an explicit quality evaluation.

### Shared synthetic Japanese evaluation set

Run the same cases against each model/revision that actually runs. Use a fixed synthetic conversation, Asia/Tokyo timezone, model prompt/template, context, decoding settings, and token budget. Record the raw output, schema-validation result, latency, and a single case outcome. Do not turn a JSON-looking answer into a tool success: call success also requires schema validation, authorization, active account/session generation, explicit approval for any external action, and an execution-time recheck. - Keep **Demo as the normal Chat mode** and leave the native flag default-off. Do not connect a failed local runtime to Cloud.
- Preserve SmolLM2 as the bounded native bring-up fixture; the latest #144 build cause is still unknown and the new branch must produce exact-head diagnostics before inference can be called a success.
