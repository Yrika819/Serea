# Security policy

## Supported development status

Serea is an early-stage project. P2's durable task runtime is complete; P3 has not started. Production provider integrations, device integrations, and real credential handling are not implemented. Do not use Serea to protect production secrets or authorize real-world side effects.

## Reporting a vulnerability

Please do not publish credentials, exploit details, or sensitive personal data in a public issue. After this repository is public, use GitHub Private Vulnerability Reporting if it is enabled. If that facility is unavailable, open a public issue containing only a brief, non-sensitive request for a private reporting channel. There is no dedicated security email address.

Do not place credentials in issues, pull requests, discussions, or commit messages.
