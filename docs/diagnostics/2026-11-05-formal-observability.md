# Formal instrumentation observations

This candidate adds a read-only observer only during the existing formal instrumentation command. It samples the three disposable-emulator package PIDs, available process RSS, thread and FD counts, device memory and OOM counter, emulator boot ID, ADB state, host memory and the observer's cgroup memory counters. Package-specific Android exit-info is sampled less often and immediately after an observed target PID disappears. Existing lifecycle, Test IME, runner and JUnit/UTP logs remain the source of test boundaries and IME events. Samples are timestamped and associated with run/attempt. Each command is bounded; host/device output is capped, and absent, inaccessible, malformed or timed-out data are explicitly incomplete. UTP may uninstall the app before exit-info is captured; no record is not proof that no termination occurred.

The observer writes `formal-observer.txt`, `formal-observer-stderr.txt` and `formal-observer-status.txt` under the existing per-API evidence directory. It is stopped before Process Death, and during interruption cleanup. Its RECORDED/INCOMPLETE state is observational and does not replace, waive or alter the Gradle exit code, JUnit inventory, campaign statuses or Required Gate. A recorded sample is not proof that an intermittent event did not occur between samples. The 20-second sampling period and bounded commands limit load but runtime impact and Android `/proc` access require emulator validation.

The observer regression suite runs in Fast CI and currently contains 14 failure-injection and behavior tests. It covers ADB disconnects and timeouts, malformed or missing PID data, PID disappearance independently of resource gaps, FD and OOM access restrictions, API 26 exit-info unavailability, exit-info timeout, command timeouts and output caps. It confirms that an unavailable `pidof` result does not erase last-known PIDs or fabricate a process disappearance. The earlier main failure at 334da4bf remains unexplained; a passing run does not establish a root cause.
