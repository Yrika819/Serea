# Personal Beta Scope

## P0
Stable Android app; safe and honestly labeled chat (demo mode if inference unavailable); persistent conversation history; local encrypted Tasks; basic accessible UI; deletion and process-death recovery; permission handling; reproducible beta package/update path; dedicated non-personal-data device acceptance.

## P1
Calendar read-only real integration (requires owner OAuth/provider approval); notifications/reminders; approved AI model route; home overlay if confirmed as a release requirement. Gmail is opt-in P1 and remains disabled absent restricted-scope approval and security review.

## P2
PC/cloud control, autonomous operation of other apps, LINE, cross-device sync, advanced long-term memory, complex agents, major UI redesign.

Personal Beta with no approved real inference must be explicitly called Demo Beta and cannot be represented as real AI. Actual GO remains an owner decision.
