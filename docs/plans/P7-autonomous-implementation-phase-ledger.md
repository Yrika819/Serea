### Cross-platform CI regression diagnosis

The first CI run after adding the recovery/evaluation harness failed in the existing `serea-capability` integration test `independent_connections_serialize_generation_activation_without_lost_event` on macOS Intel. The test helper had assigned both prepared generations the same manifest and schema-catalog digests. The extracted P5 fix intentionally treats those rows as the same manifest and allows only one activation, so the active generation depended on which thread acquired the writer first; the test incorrectly required the higher row in that duplicate-content case. The schema/storage behavior was consistent with the P5 idempotency contract. The regression test now prepares distinct manifest digests for its generation-order assertion; identical-manifest coalescing remains exercised by `concurrent_same_manifest_startup_yields_one_generation`. The corrected concurrency test passed 30/30 local Linux x86_64 repetitions. Updated macOS Intel CI is still required before marking the final PR head green.
