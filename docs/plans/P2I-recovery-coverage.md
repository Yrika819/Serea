# P2I Final P2G Recovery Coverage Matrix

This ledger reconciles the final disposition table in `P2G-review-and-closure.md` (lines 106–138) to production branches and regression evidence. `COVERED` means a production decision, durable behavior and repeat/race story have a representative test or a stated invariant; this is not a mathematical proof of every SQLite byte corruption.

`recover()` is one audited transaction plus `RecoveryPass::recovery_pass` savepoint (`crates/serea-task-engine/src/recovery.rs:68–86`, `crates/serea-storage/src/recovery.rs:272–292`). Each action rechecks catalog/FKs, reinspects the task fingerprint, validates the action and performs conditional writes within an operation savepoint (`storage/src/recovery.rs:482–561,727–842`). Errors roll back the whole pass; report publication occurs only after the transaction returns success. `TaskJournal` is the only semantic recovery audit mapper (`task-engine/src/journal.rs:13–44`). Identical explicit time/context reruns are pinned by `stable()` in `tests/recovery.rs:386–408`; file-backed race families are at `:2049–2256`.
